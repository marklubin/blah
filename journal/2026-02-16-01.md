# Session Journal - 2026-02-16-01

## Summary
Implemented LinkedIn + Reddit Radar flows across 4 phases. Added a full PRAW-based Reddit adapter following the existing Twitter/Bluesky adapter pattern, LinkedIn ingest infrastructure (CLI command + batch DB insert + browser scraping tools), and wired everything together into the pipeline, config, CLI, and agent system. All 245 tests pass.

## Decisions Made
- Reddit adapter uses PRAW with the same `PlatformAdapter` interface as Twitter/Bluesky
- Reddit `follow()` maps to subreddit subscribe (not user follow, since Reddit doesn't have that)
- Reddit `post()` uses first line as title, rest as body; uses `link_card` field for subreddit name
- LinkedIn has no adapter — items enter via `blah radar ingest` CLI or `store_linkedin_items` agent tool, then `blah radar pull --skip-poll` processes them
- Pipeline explicitly skips LinkedIn sources during `_poll_sources()` with a log message
- `blah radar pull` no longer requires API adapters if only LinkedIn sources exist (or if `--skip-poll`)
- Char limits: Bluesky=300, Twitter=280, Reddit=10000, LinkedIn=1300
