# Session Journal - 2026-03-03-01

## Summary
Implemented the browser adapter plugin layer — a uniform fallback system where every platform (Reddit, HN, Twitter, Discord) gets browser scraping tools following the existing LinkedIn pattern. Also added `blah radar sync discord` for auto-populating Discord channel sources, updated the health check with a browser/MCP router row, generalized pipeline skip logic, and enabled Reddit in config (browser-only, no API creds needed).

## Decisions Made
- Discord browser tools are lightweight (check_auth + scrape_instructions only) since Discord already has a working API adapter and store/sources tools — avoids duplication
- Browser (MCP) health check runs first in `_check_all_platforms` so other platforms can reference `browser_ok` for their fallback status
- Pipeline skip logic changed from `if platform == "linkedin"` to `if adapter not found` — any platform without an API adapter gets the same browser-scraping skip message
- Reddit enabled with no API creds — browser fallback covers it
- `blah radar pull` status messages generalized from LinkedIn-specific to showing all browser-only sources grouped by platform
