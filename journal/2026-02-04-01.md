# Session Journal - 2026-02-04-01

## Summary
Implemented Phase 1 of the Blah MVP: project skeleton, persistence layer, configuration, CLI with all commands stubbed, and `blah init` / `blah status` fully working. All 21 tests pass and ruff linting is clean.

## Decisions Made
- Nested config classes use `BaseModel` not `BaseSettings` to avoid pydantic-settings picking up unrelated env vars (e.g. `PATH` conflicting with `ContextConfig.path`)
- Used `StrEnum` instead of `(str, Enum)` per ruff UP042 for Python 3.12+
- Kept `uv_build` backend as specified in plan (existing pyproject.toml used it)
- Resource linking uses separate join tables (`rant_resources`, `piece_resources`) rather than embedding in JSON
- Repository layer returns plain dicts rather than Pydantic models for simplicity — models exist for validation/typing but DB layer stays lightweight
