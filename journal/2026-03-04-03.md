## Engagement Principles

1. **Add, don't echo.** Every comment must contain information the author didn't already have. No "great post!" No "this is interesting because [restates the post]."
2. **Lead with questions.** Questions signal genuine interest and invite conversation. Statements signal broadcasting.
3. **Concrete > abstract.** "We hit X when building Y" beats "this is an important problem."
4. **CDR only where natural.** Don't crowbar it in. Best entries: agent civilisation, directed compression, Vectorize taxonomy. Don't mention it on the MCP or sandboxing threads.
5. **Platform norms.** HN: technical depth, no self-promo, no emojis. Twitter: concise, threads OK for depth. Discord: conversational, links OK.
6. **One engagement per thread.** Post once, respond to replies. Don't dominate threads.

## Pipeline Issue Identified

The triage scored 10 dead threads (42-448 days old) at 0.90 because relevance scoring doesn't account for freshness. HN search returns old results and the pipeline treats them identically to frontpage items.

**Fix needed**: Either filter by age before triage (e.g., skip items > 14 days), or add a freshness multiplier to the triage score. The former is simpler and probably correct — stale threads have zero engagement value regardless of topic relevance.
